# Changelog

All notable user-facing changes are recorded here. This project follows
[Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-08-06

First public release.

- Cross-platform PTY/ConPTY companion for the official Codex CLI.
- Responsive one-to-three-row HUD with model, context, tokens, limits, Git,
  worktree, tools, plans, compactions, permissions and Agent activity.
- Keyboard-first configuration, live preview, 13 themes and accessible linear
  fallback.
- Exact active-session telemetry through an optional loopback app-server relay,
  plus safe hooks/account/local fallbacks with visible source health.
- F2 Agent Inspector with a bounded summary and handoff to Codex's official
  `/agent` picker.
- Owned, reversible `codex` shim; the official executable is never overwritten.
- Checksum-verified installers and release archives for macOS, Linux and
  Windows x64.
